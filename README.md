# App Perpustakaan

Aplikasi manajemen perpustakaan berbasis web yang dikembangkan menggunakan framework Laravel untuk mata kuliah Workshop Pemrograman Framework.

## Tujuan Aplikasi

Aplikasi ini bertujuan untuk memudahkan pengelolaan operasional perpustakaan secara digital, meliputi manajemen katalog buku, data anggota/pengguna, transaksi peminjaman dan pengembalian, serta pencatatan riwayat perpustakaan secara efisien dan terstruktur.

---

> **Perbedaan Model, View, dan Controller (2-3 Kalimat):**
> 
> **Model** bertanggung jawab mengelola struktur data, logika bisnis, dan interaksi langsung dengan database. **View** bertugas menyajikan antarmuka visual (UI) dan menampilkan data kepada pengguna. **Controller** bertindak sebagai perantara yang menerima permintaan (request) pengguna, mengolah data melalui Model, lalu mengirimkan hasilnya ke View yang sesuai.
